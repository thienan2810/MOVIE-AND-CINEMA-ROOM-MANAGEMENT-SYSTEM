# MOVIE AND CINEMA ROOM MANAGEMENT SYSTEM

This is my second-year final project on a movie theater management system. 
The project focuses on designing the database and building a management application using Python.

*   **Language:** Python
*   **Database:** MySQL
*   **Library:** `mysql-connector-python`

## 🚀 Main operations
*   Manage movie information and showtimes.
*   Book tickets and manage seating in the screening room.
*   Compute revenue and generate reports.
*   Secure your data using Parameterized Queries to protect against SQL Injection.


## 📝 How to use
1. Create tables: `Create_tables.pdf`
2. Download the dataset from `cinema_dataset.xlsx` then import the data from Excel using `import_data.py`
3. Advanced application: `Advanced_Database_Objects.pdf`, `Database_Security_and_Administration.pdf`
4. User Interface (Section 4 is staff only): `Python_Application_Development.py`
